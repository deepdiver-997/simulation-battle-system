# Simulation Battle System — 回合制精灵对战模拟引擎

## 项目概述

基于 C++20 的回合制精灵对战模拟引擎：以有限状态机驱动战斗流程，按"时点"调度效果执行，机制以数据形式注册进内核，而非硬编码。适用于对战模拟、AI 自博弈训练与机制研究。

当前处于积极开发阶段，核心对战流程已可运行，效果系统与场景化测试持续扩展中。

## 架构一览

数据（SQLite）→ 组装层（精灵/技能对象）→ 效果内核（注册表 + 时点桶）→ FSM 逐时点驱动 → 效果执行并读写战斗上下文。

- **内核固定、机制是数据**：内核只提供少数注册表（效果、规则、免疫、盔等），新机制不修改 FSM。
- **效果插件化**：效果实现以动态库插件形式加载，与内核通过 C 接口解耦（插件源码与数据构建管线现状见下文"数据与插件"）。
- **时点语义化**：状态机的每个状态对应一个固定的效果注册时点，保证判定顺序可预测。

## 功能模块

1. **对战系统**：技能释放、属性克制、伤害管线、状态异常等核心对战逻辑。
2. **效果系统**：事件中心、规则中心（免疫/盔/封属）、时点桶调度、持续效果管理。
3. **实体组装层**：精灵、技能、印记等战斗实体的构建与数据装载。
4. **数值计算**：伤害公式、克制倍率、能力等级修正。
5. **服务器支持**：自研 reactor 网络层（macOS kqueue / Linux epoll），一局一房间的多客户端对战服务。
6. **场景化测试**：每个机制场景一个可执行用例，持续验证判定口径。

## 技术栈

- **语言**：C++20
- **网络**：自研 reactor（kqueue / epoll），无 Boost 依赖
- **数据**：SQLite（只读查询仓库层）、nlohmann/json
- **并发**：自定义线程池 / IO 线程池
- **构建**：CMake (>= 3.18)
