# 内核耦合效果清单（贡献边界）

这批效果的实现**不在效果插件层，而在内核源码里**——它们涉及时点路由、
管线阶段、申报制通道或内核常量。对它们的改动等同内核改动：
**必须先开 issue 拿 `kernel-approved` 标签**，不接受直接 PR。
维护者侧：这批由夜跑管线自产（实现成本低于审核成本）。

（伤害结算后读台账、击败后、命中钩子等），先来这里讨论：

```

```

复算命令（本清单随之更新）：

```bash
awk '/State effect_register_state/,/^}/' src/entities/skills.cpp \
  | grep -oE 'case [0-9]+' | awk '{print $2}' | sort -un
```

⚠️ 条件先制族（2020 同族）**不要**在这里加 case——选择期路由走 DB 表
`custom_skill_selection_routes`（J66 勘误：用技期路由赶不上首回合先制判定）。

## 3. 管线阶段与申报制

- 红伤管线 FLOOR（保底）/ CAP（锁伤）阶段目前**零注册**——第一个用它的
  效果需要连同阶段语义一起过审；
- 概率异常施加走申报制 `apply_anomaly_checked`（概率写审计槽，场景可做
  无随机精确断言）——概率补偿类效果请对齐此通道，不要自造随机断言。

## 4. 判定惯例（改这些 = 破坏性变更）

- 「未触发」口径：对手等级到 -6 钳底视同未触发，SUCCESS 才算落地
  （90212fef 全族翻转，勿回退）；
- 本体/视图分离：公式读回合内视图，视强为弱等语义在视图层；
- 事件原语成功路径 emit：效果层消费事件，不改事件中心。
