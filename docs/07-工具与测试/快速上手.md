# 快速上手——数据管线、编译、运行、测试

> 面向第一次检出本仓库的开发者。前置：CMake ≥3.18、C++17 编译器、Python 3、
> sqlite3 命令行工具。浏览器调试台另需 Node（仅构建前端时）。

## 1. 数据管线（必做——引擎启动就吃这个库）

```bash
cd scripts
python3 fetch_seer_unity_bytes.py      # ① 拉官方 Unity 配置（社区镜像，30 分钟一刷）
python3 decode_seer_bytes.py           # ② 解码为 JSON（依赖 pip install seerapi-solaris）
python3 import_seer_unity_sqlite.py    # ③ 导入 SQLite → data/processed/seer_unity.sqlite
cd .. && sh tools/db_patches/apply_all.sh   # ④ 重放本地数据修正补丁（不可省！）
```

⚠️ 第三步重建库会回到官方原值，**第四步必须接**——`side_effect.arg_count` 等表的
本地修正（证据见 `tools/db_patches/` 各 .sql 头注释）会被官方原值冲掉，漏了它
部分切片敏感测试会红。
⚠️ 仓库跟踪状态：③（import）已入库；①②（fetch/decode）随数据线分批开放——
缺失时向维护者索取（同目录同名脚本）。
解码若报 "exceeds buffer length"：多半是下载截断，重拉该 .bytes 即可。

可选：`reference/scrape_4399/`（4399 图鉴文本语料，机制口径参考，非运行时依赖）——
按其 README 三步抓取/导出。

## 2. 编译

```bash
cmake -S . -B build && cmake --build build -j8
```

产物：`build/sim_server`（对战服务）、`build/sim_training_cli`（命令行客户端）、
`build/sim_scenario_*`（场景测试，每场景一个二进制）、`build/sim_fuzz_battle`（fuzz）。

## 3. 运行

```bash
./build/sim_server                     # 对战服务 127.0.0.1:4399（须在仓库根运行）
./build/sim_training_cli               # 命令行客户端（auto 可自动对打）
web/up.sh                              # 浏览器调试台（网关:8070 + 前端）
```

服务端/客户端玩法见 [命令行客户端使用说明](命令行客户端使用说明.md)；
要自研前端/机器人：[线协议规格](线协议规格.md)。

## 4. 测试

```bash
./build/sim_scenario_960_effect63_reflect_verdict   # 单场景（退出 0 = 过）
sh tools/night/build.sh                             # 全量构建 + 全场景回归（推荐门禁）
python3 tools/taskctl.py selftest                   # 看板工具自测
```

场景 = `test/scenario/scenario_NNN_<名字>.cpp`（CMake GLOB 自动收录，新文件免登记）。
对局 fuzz：`build/sim_fuzz_battle --from 0 --count 2000`（用法见 test/fuzz/README.md）。

## 5. 目录速览

| 路径 | 内容 |
|---|---|
| include/ src/ | 引擎内核（FSM/效果系统/原语/服务端） |
| resources/ | 效果插件动态库源码（moves/soul/suit 三库，构建时部署） |
| scripts/ | 数据管线（Python，见 §1） |
| test/ | 场景化测试 + fuzz（本地维护） |
| tools/ | taskctl 看板领取器、db_patches、覆盖率/语料工具 |
| docs/ | 架构与协议文档（本文所在） |

效果实现入口：`resources/moves_lib/`（技能效果，按家族一文件）与
`resources/soul_lib/`（魂印，按精灵一文件）——注册宏 `SKILL_EFFECT(id, fn)` /
`SOUL_MARK` / `SOUL_PROGRAM`，检索直接 grep 效果 id。
