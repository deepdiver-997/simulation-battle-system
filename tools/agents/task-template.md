交付 = **一个可 --no-ff 合并的 feat 分支**：实现 + 场景断言 + 全量门绿 + 看板留痕。

## 硬性规矩（历史事故换来，逐条有人踩过）

- **立单三查 + 跨 worktree grep**：动工前查 ①内核无同号硬编码 ②effect_info 无同文
  模板 ③全库 soul_lib/moves_lib 并集无注册——**包括其他 worktree 的未合并分支**
 （撞号=换号重发，K291/K292 重复单事故）。
- **场景号段先 alloc**：在 `docs_local/tasklog.jsonl` 记 `{"action":"alloc",...}`
  再用号（号段 = tasklog 里的既分配段，不侵占）；魂印行参一律 `db_at`（owned_int_args
  原序），**禁止读 a.row**（偏移 2 位坑，见交接文档）。
- **pct 行参在位即消费**：`>0` 守卫会把显式 0 关闸档盖掉（K314/K340 两犯）。
- **红伤相管线只在技能结算里跑**：`deal_damage(NORMAL)` 直调是裸扣血路径——场景
  测红伤挡下/减伤必须真实技能驱动（2993 探针记档）；粉伤直调可测。
- **int 乘区一律 `checked_pct_mul`**（calculation.h）：溢出会响亮 throw，那是场景
  HP 堆太大了——改小测试值，**不要绕**。
- **看板走 taskctl、留痕进 tasklog**：领单/完成都要落账（主板调用，别在 worktree
  裸调 taskctl——会写错板）。

## 完成 = 过门 + 汇入集成批

```bash
tools/agents/gate.sh            # ① 全局构建锁 + 全量场景回归 + registry dump
tools/agents/collect.sh <name>  # ② --no-ff 汇入当日 integration/<日期> 批分支
```

②是①之后的规定动作：夜跑产出**不要**留成一堆待审核分支/工作区——完成即自汇入
共享批分支（冲突当场在你上下文里解，别攒到验收爆），然后
`tools/agents/remove-worktree.sh <name>` 收工作区（已汇入会被认账）。
验收侧对批分支**一次过门、一次合回主干**。汇入冲突时的判例参考
06-交接/合并记录-*（看板 md 冲突按行级 ✅ 优先裁决）。

全绿后在 task.md 底部写收尾报告：做了什么 / 断言口径与实测值 / 勘误记档 /
注册数变化（SOUL_PROGRAM 只增不改）。红门不许交，报错信息里有改法。

## 红线（无人值守的 fail-closed）

- 磁盘预算不足（exit 2/1/78）→ 停，写报告说明，不要清理别人的工作区腾地方。
- 构建锁超时（exit 75）→ 报告等待时长；连续超时说明机器过载，停。
- `.git/agents/STOP` 哨兵存在（exit 76）→ 人已刹车：提交当前进度、写报告、收工。
- 不 push、不动 `main`/`main-local`、不删别人的 worktree 或分支；合并由集成会话做。
