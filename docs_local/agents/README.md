# Agent 任务台账

> 建于 2026-09-17。回答一个问题：**每条机制线现在归谁、做到哪、从哪续**。
> 多 agent 工作流的排期见 `docs_local/多agent协作工作流.md`（怎么开工作区、怎么合并）；
> 本目录管"任务本身"。机制线的技术细节交接仍写在 `docs/06-交接/`，这里只放索引。

## 用法

1. **领任务**：在下面表里加一行，写清 worktree / 分支 / 任务目标 / 恢复入口（从哪份文档哪个场景继续）。
2. **做推进**：改"状态"列 + 在"进度备注"追加一行（日期 + 一句话）。细节写交接文档，别在这里堆。
3. **做完收尾**：状态改 ✅，确认分支已合并回 `main-local`，再删 worktree + 分支
   （`git worktree remove ~/.agent-workspaces/workspaces/sbs-local/agents/<名> && git branch -d feat/<名>`；2026-10-24 起工作区迁移，旧 `../agents/` 为历史区）。
   **没做完就别删**——worktree 里未提交的东西 git 救不回来。
