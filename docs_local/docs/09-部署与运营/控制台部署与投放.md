### 构建与升级

```bash
# 本地构建（amd64，ubuntu:22.04 对齐服务器 glibc；-march=x86-64-v2 对齐 Ivy Bridge）
docker buildx build --platform linux/amd64 -f deploy/Dockerfile -t sbs-server:amd64 --load \
  --build-arg HTTP_PROXY=http://host.docker.internal:7897 \
  --build-arg HTTPS_PROXY=http://host.docker.internal:7897 .
# 部署（自动：抽取→容器内挂真 DB 冒烟→rsync→venv/token/registry→重启→健康检查）
sh deploy/deploy_racknerd.sh
```

⚠️ 代理 build-arg 必带：容器内 127.0.0.1:7897 不通，必须指 `host.docker.internal`。
⚠️ 服务器**永不编译**（1G 内存）；bundle rsync `--delete` 会清目标侧空目录，数据目录 mkdir 必须在其后（脚本已修）。

### 排障 / 轮换

- 日志：`journalctl -u sbs-gateway -n 50` / `-u sbs-sim`；内存：`free -m`
- 重启：`systemctl restart sbs-sim sbs-gateway`（重启 = 清空鉴权封禁内存态）
- 轮换渠道令牌：改 `/opt/sbs/sbs-gateway.env`（删旧加新）→ 重启；私人令牌不动
- 已知遗留：HTTP 无 TLS（token 明文头，小范围可接受）；要上域名+证书再说

## 三、事故与变更记录

- **2026-09-28 鉴权封禁误伤**（88×403，Mac/iPhone/内嵌同出口 IP 全锁 30 分钟）：首访无 token 的页面请求全计入失败阈值 + 封禁检查先于 token 校验。已修（auth.py 三处治理，1a01fce）：正确 token 先于封禁放行；无 token 不计失败；阈值 5→10。重启即清内存封禁。
- **2026-09-28 部署脚本目录顺序 bug**：bundle rsync `--delete` 清掉先建的数据目录 → 传 DB 报错。已修：mkdir 移到 bundle rsync 之后（402ac3b/f9a4bfc）。
- **2026-09-28 Linux 可移植性**：gcc11/libstdc++ 不传递包含（mutex 族 + elemental-attributes vector/string），8 文件显式补齐（6823653）；容器内 113 TU 语法全绿。
- **2026-09-28 培养预览"换性格不动"排查 + 升级**：用户报远端培养预览换性格无反应。排查结论：引擎/网关/前端全对（本地 UI 实测 404→442 实时变，API 双性格 527/565）——根因是**远端停留在旧构建**（资产 BR8SwFn4 vs 本地 BhImoYn9）。已 docker amd64 重建 + 全家桶升级，公网双性格复测通过。
- **2026-09-28 公共令牌丢失（升级时发现）**：`/opt/sbs/sbs-gateway.env` 只剩一把随机 token，README/广告公开的 `sbs-3021308f` 不在 → 公共用户全 401（广告当日上线）。已把公共令牌并入 env（保留既有随机 token）并重启，复测 200。⚠️ 文档表里的私人令牌 `2c4c58f1…` 在服务器上已不存在——现状那把随机值应即现行私人钥，换钥按"轮换"节操作。
