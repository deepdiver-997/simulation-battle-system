## 二、魂印六条实现口径

- **帝君之罚/之赐**（登场）：1263 同款双通道——`EVENT_ENTER_STAGE`（只发换宠）计数 + `ENTER_EXIT_STAGE` 节点部署兜底（`battle_start_done` 幂等）。首次 1/3、之后 1/9；1308 的 `next_entry_no_decay` 旗标消费一次。罚只打**不在场存活**精灵、**钳底 1**（"致死时残留1点体力"——罚的击杀永远死不成，不走死亡漏斗）；赐同集合恢复（钳上限）。场下扣血前查武心婵保护门（咤克斯先例），恢复不查（保护门只挡"减少"）。
- **帝君之援**（满体力登场先制+1）：`EVENT_ENTER_STAGE` watcher 给**任何满体力登场的己方宠**打戳（写该宠 `on_stage_storage`，引擎换宠自动清 = "本次上场"生命周期）；部署宠由 arm 节点补戳（`roundCount==0` 幂等）。消费 = ROSTER 作用域 MOVE_RIGHT 节点（memset 后跑，+1 不被冲；受束缚清零，官方口径）。ROSTER 节点随宿主阵亡停刷新 → 阵亡帝君不再提供（"在出战背包"按存活解释）。
- **帝君之御**（老魂免）：① 抗性两槽（fixed/percent = 100）走**战前魂印补丁** `SOUL_PRE_BATTLE(1128, STAT_MODIFY)`（2026-09-20 用户拍板：抗性提升是"天生/游戏开始前"的面板事实，走既有补丁注册面被识别、init_battle 扫 12 槽直接改 pet 的两个抗性槽，**不随登场触发**、与上下场无关；sync 每回合重基 ws 视图）；② PINK_DAMAGE + ANOMALY 全 mask 免疫票（ROSTER、`duration_rounds=0` 永久、**Ancient 层**——语料《浅谈主动毒与魂印免控判定》把天启帝君列入"老魂免"名单，Ancient 层连主动毒一起挡；票在 arm 节点授予——战斗开始全 12 槽激活 ROSTER 节点，场下帝君也即刻生效）。消逝时 EVENT_VANISH 推送撤票（武心婵同款）。
- **帝君之阵**：±10%/阵亡走 **ws 加算通道**（`damage_add_pct` / `damage_reduce_add` 空槽）+ ROUND_START STAGE 节点每回合重写（776/32 套路，切换作废免费获得）；阵亡数 `count_dead(ALL)`（battle_primitives.h 注释预留的"帝君=ALL"口径）。"己方最后存活→回合类效果免消除"与"对手最后存活→封回血"：EVENT_DEATH watcher 每次死亡重判，固定句柄（11283/11284）grant/revoke。
- **帝君之殒**：EVENT_DEATH（target=帝君）→ 30% → 对手随机一只不在场存活精灵 hp=0 后走 **defeat_pet 死亡漏斗**（场下真2命复活照常响应，圣光灵神口径；与罚的"钳底 1"不同，殒是真杀）。

## 三、技能侧要点

- **内核改动（唯一）**：`src/entities/skills.cpp` 的 `effect_register_state` 加 5 个 AFTER_ACTION 分支：505（暴击回血，读 `resolvedDamage.isCrit/final`）、1208（反转族 1221/521 同口径——本次伤害用反转前等级）、1306/1307/1308（"造成的伤害/击败与否"伤害落地后判定，1256 同款）。
- **1299+1300（轮回之狱域）**：域窗口存 `plugin_storage`（1299000/1300000+side，408 套路，重复使用只刷新窗口）。1299 ① = EVENT_TAKE_DAMAGE watcher（对手裸伤 <300 → 对手场下 -100 钳底 1）+ ② ROUND_END tick（对手本回合用了属性技 → 己方场下 +100；roundChoice==SELECT_SKILL 且 `skills[idx].type==Attribute`）。1300 = REDUCE_PCT 管线回调（受伤 -50%）+ watcher（裸伤 >280 → `attach_random_anomalies` 2 种，`landed==0` 才消对手回合）。
- **821**：`grant_immunity(BREAK)` 回合数 = rounds +（后手 ? 1 : 0）。
- **1304（忽略双防）**：无现成通道 → 窗口内 ROUND_START tick 把 `ws.battle_attrs[对手]` 双防 ×75%。**依赖"sync（回合开始）先于 ROUND_START 桶"的既有顺序**，每回合对新鲜值乘一次不叠加；已知边界：窗口内对手换宠会重基视图（该回合余下时间失去削减）。
- **1302/1303（终焉时刻）**：1302 = `all_stats_up(+1)`，50% 翻倍（一次掷点二分支：翻倍 或 吸取强化 `transfer_stat_boosts`）。1303 = 597 同构 AFTER_ACTION 双桶 tick（`used_skill_this_round` 门），低血（<1/2）翻倍实现为**两次 drain_hp**（两段独立结算——次数型免粉各挡一段；实测若要求单段双值只改这里），满体力时吸取照常、回血转给己方场下 +100。
- **1315**：独立掷点 → `ws.must_crit`（会心 1~5 星"独立二次结算"口径）。
- **1316/1317/821 的先/后手判定**：**读 `preemptive_right`（先手权解析结果），不读 currentState 桶位**——对手嗑药时引擎把唯一行动方的动作提升进 FIRST 槽（且先手权判嗑药方让先），桶位判定会静默翻转。090 的 J2 实测踩坑后改定；辅助函数 `is_first_mover` 在 tianqi_dijun_skills.cpp 内，将来通用化可挪 moves_lib/common.h。
- 简单技：虚空叹息（749）/不朽圣魂（585）引擎已有，零新代码。

## 四、场景 090 结构（10 组）

A 罚/赐部署（含致死钳底 1）· B 御（Ancient 免异常/免粉、红伤照常）· C 阵 ±10% + 最后存活免断 + 封回血 · D 阵 技能后回 1/10×场下数 + 等量百分比 · E 援（对照/满体力翻转/非满体力不加）· F 轮回之狱（低伤扣场下/残留 1/域内免断/属性技回场下）· G 终焉时刻（全属性/吸取/忽略双防视图/下回合先制翻先）· H 天君启示录（1305 账/反转→封攻击白板）· I 纵横三千界（低伤扣场下/未击败回场下/击败置 1308 旗标）· J 灵魂救赎（先手随机 3 项/后手回 1/4）。

测试技巧（本场景新增的两条，后续通用）：
1. **CHOOSE 停泊期直调原语后必须手动 `ctx.event_center_.drain(&ctx, roundCount)`**——emit 只入队，drain 由 FSM 在状态桶后调；否则 watcher 看不到事件（C 组踩坑）。
2. **嗑药会改写先手权**（"嗑药方让先"，battleFsm 硬编码）且唯一行动方的动作进 FIRST 槽——测"先/后出手"分支时对手要真出手（J2 踩坑）。

## 五、BOSS 无效口径

罚/御/殒（及阵的非 ±10% 子句）tips 标注 boss 无效/有效——引擎不建模 boss 战（PvP），全部按 PvP 落地，与 1263/1067 先例一致。
