## 三、勘误与记档（日班必读）

1. **事件派发时序（本夜最大坑，3 单踩过）**：插件/场景直呼原语的 `emit` 只**入队**，
   下一次 FSM run 才派发给 watcher——场景断言必须空转一拍；ENTER_STAGE 派发再晚
   一个 drive 边界（J111）。J59/J111 场景因此返工。
2. **per-attack 事件不可达（J100 记档）**：EVENT_SKILL_USED 的 drain 晚于命中 roll
   （实证失效）；BEFORE_SKILL_HIT 锚点每回合仅首动方一次（二动方收不到）→
   "下 N 次攻击 X"类只能按 J18 1204"次≈回合"取回合窗。
3. **179 盘点假阳性**：核心 effect_unit_parser.cpp:145 已内建（SameElement
   pet-vs-pet + PowerBoost **平直** +{0}）——插件注册会被解析路径遮蔽（实证函数
   不执行）。**建议日班把 unit 解析效果并入盘点口径**，J51 对 179 的旧记档实为冗余。
4. **must_hit 绕过命中 roll**：场景造 miss 必须 accuracy=1 **且** must_hit=0
   （J108 实证假命中）。
5. **非 inline 方法插件不可直调（教训 #4 再 +2）**：has_active_abnormal_status、
   set_abnormal_status_end_round 必须走 CoreApi 槽（J62/J105 各踩一次，链接期即爆）。
6. **载体自带基值先制泄漏次轮**（16327 prio=2）：跨轮先手对照不能用同载体，改基线法
   （J105）。另 Skills::execute 的 return MISS 出口照发 EVENT_SKILL_INVALID（1320
   通道可靠）。
7. **submit_operation 内部就跑 FSM**：before 读数必须在提交前（J57 场景返工一次）。
8. **烧伤语义发现**（J104）：烧伤自带威力减半（materialize 时 is_burn_effective），
   513 的 ×2 在烧伤档净效果=补回正常威力——"补倍"语义，测试要用毒档。
