## 二、本夜关键发现（白班必读）

1. **【内核时点·重大】TAKE_DAMAGE watcher 交付推迟到 AFTER_ACTION**：事件携带的
   state 是攻击伤害时点，但回调实际在 AFTER_ACTION 才跑——届时"对手处于 X 状态"类
   查询面已过期（实测睡眠在承担方行动处理时即被清）。**条件查询类附加效果一律走
   管线 DETECT 相位同步查询**（293 改造后落地）。K3 反弹族 watcher 不受影响（读
   ev.amount 快照而非实时状态面）。
2. **【内核时点·重大】FIRST_ON_SKILL_HIT 命中即醒**：受击方睡眠在命中时点被清
   （先于 ATTACK_DAMAGE）→ "若对手处于睡眠状态"的攻击系条件在本引擎时点序下恒假
   （2697 太古邪灵行记档，与官方"打醒"口径一致）。同族"睡眠门"载体立单前先查此坑。
3. **【断言方法论】skill_power_view rewritten 重算会重掷 85%~100% 浮点**：威力改写
   族（242/733/134）的伤害比例断言不可对齐（首跑实证 2198 vs 2084）——**必须用
   SKILL_EFFECT 时点字段断言**（debug_step 停泊读 view）。addPct（damage_add_pct）
   则是公式内取整，外部 ×N 差 ±1%，行为断言只能方向性。
4. **【数据·247 面板批】六元组槽序五行互锚定案：pos0攻/1防/2特攻/3特防/4速/5体**
   （数值属性槽，与等级槽 5=命中两套索引）。⚠️ 纳斯克 2278 args 与 tips 冲突（判复制
   粘贴数据错误）、幻瞳 args 缺速度——**tips 建表为权威**；阿苏/比伯/加特/提普
   4 宠进化同 id 双行记档（需形态区分机制）。
5. **【事故两型】**（均已修复并在代码头注留档）：

     g_core->has_active_anomaly 槽；
