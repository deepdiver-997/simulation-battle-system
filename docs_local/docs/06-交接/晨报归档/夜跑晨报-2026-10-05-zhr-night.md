## 二、白盒发现（建议 R 组/白天核对）

1. **K 系魂印的正确实现形态（本夜核心产出，新单必读）**：
   - 每回合节点必须**声明进 SOUL_PROGRAM**（SoulMarkManager 更新器每回合
     ROUND_COMPLETION 重注册进魂印桶）；arm 节点里经 register_skill_effect 手工挂的
     桶效果会在更新器重建后失效（K12 310 FMR 挂法实测 R2 起不触发）。
   - **对手行动反应不进声明桶**：桶按 (state, 持印者) 配对，对手行动时执行的是对手
     侧桶——持印者条目永不触发。正解 = EVENT 面 watcher（K2 262 同款；
     1314 命中/未命中旗、1843 属性技旗均此形态）。
   - 手工 SoulMark（场景构造）的行参：bind_soulmark_args 会**丢弃行参前两位**、
     合并 [own, opp, slot] + 行参[2:]——实现侧行参一律从**绑定后 args[3:]** 读；
     场景构造传 {0, 0, 参...}（K165 实测：{3,100} 直接传会丢参走 fallback）。
2. **preemptive_right 在 FMR 桶执行前已重置为 NONE**（handle_BattleFirstMoveRight
   先 memset/重置后跑桶）——"上一回合先手权"类计数必须在 ROUND_COMPLETION 收口
   （pr 在该时点仍为当回合值），K12 310 实测记档。
3. **ws.preemptive_level 的 memset 在 MOVE_RIGHT 时点**——ROUND_START 写的先制
   降/升会被清；K12 310 / K163 无涉、但任何"下回合先制±N"都须在 FMR 桶写
   （1123/636 同款）。
4. **EVENT_SKILL_USED 时点写 skill_power_view 会被物化覆盖**——威力条件改写必须在
   SKILL_EFFECT 时点（K4 636 直系；K165 291 实测记档）。该时点 skill_use_seq 尚未
   自增 → executed_* 门不可读，攻击技门用 roundChoice+技能表类型（636 同款）。
5. **must_hit 攻击绕过 hit_rate_mod_attack 乘区与 hit_invalid 封技**——命中率/封技
   类断言不得给攻击方置必中（K165 实测）。
6. **击杀后 AFTER_DEFEATING_OPPONENT 状态被跳过**（击杀侧 on-stage dead 时
   battleFsm:2213 直接转 CHOOSE_AFTER_DEATH）——"击败对手后"节点应挂
   BATTLE_AFTER_DEFEATED（双侧桶，trace 实测每杀必经）；K12 319 实测记档。
