## 三、实测记档（防重蹈，建议合并后沉淀进常识/SOP）

1. **worktree 内 taskctl 操作会踩陈旧板文件/锁**：`.git` 是文件 → `taskctl.lock` NotADirectory；
   看板 done 一律回主工作区跑（两次踩到，finish.sh 从 worktree 调用时 done 静默失败）。
2. **单编插件 target 不跑 `*_deploy`**（红线 2 实证第二次）：soul_plugin 编了、resources 里
   dylib 还是旧的 → 新注册全部不生效（K181 免疫票"不落账"查了半天就是它）。
3. **场景构造 SoulMark 要显式 `sm.monster_id`**：DB 行才有，行级 boss 门/monster 分支读它
   （K178 T3102 首跑翻车点；2890 同款 helper）。
4. **grant_immunity 的 source_id 必须 0（新建）**：非零=复用更新句柄，自造句柄不落票
   （K181 首跑免疫 0 生效）；soul=false Modern 层走施加链 [3] 早检查（artemis 口径），
   diwang 的 Ancient+soul=true 是"连主动毒都挡"特化。
5. **断回合可断面不含 seal_skill 票**：次数型/回合型封属在 has_round_effects/has_round_type
   均不可见（break 返回 NO_EFFECTS，K188 实测记档）——断回合观测/实现载体须用
   ContinuousEffect 回合窗（场景直种 = moves register_round_effect 同构）。
6. **暴击掷点在 query_usage ①.5（ON_SKILL_HIT）**：先于 EVENT_SKILL_USED/SKILL_EFFECT；
   事件面写 ws.must_crit 惠及不到本次攻击（ws 每回合 reset → crits 恒 0 实录）。
   当次必爆正位 = J136 ACTION_START tick + roundChoice/SkillType 选技判攻（skills.cpp:546 记档）。
7. **时长型免异常票窗界 [R, R+1]**：授予回合 + 次回合（回合完成递减），K181 T3143 实证。
8. **MOVER_DEATH 态每回合都走**：死亡节点须自帶"同尸"门（pipeline_valid_id epoch），
   否则账本被反复重置（K188 实测）。
9. **场景宏传三元消息要加括号**：CHECK/CHECK_EQ 的 msg 展开后 `<<` 优先级高于 `==`。
10. **make_pet(hp=50000) 把上限也设成 50000**：回血类断言要 max 大 + 开局后压当前体力
    （3020 同款），否则 heal 被钳 0（K194 首跑翻车点）。
