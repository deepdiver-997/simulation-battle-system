## 二、拦截关系（本批次的机制核心）

官方语义："链接方计算**受到的**攻击伤害时**不计算克制倍数**"——倍数计算整个被接管，
"克制倍数至少为2"锁**没有作用对象**（与 idx094 莫妮卡最优系别同款：不是谁覆盖谁，而是锁
先失去对象）。引擎表达（零内核改动）：

1. 伤害公式的克制倍数读 `ws.restraint_view[攻击方]`（>=0 直写覆盖，`calculation.h:47`）；
   写入窗口 = 伤害公式（`stage_simple_attack_damage`）之前 → SKILL_EFFECT 时点桶。
2. 锁节点（1164，STAGE）与链接镜像节点（2197，TEAM，注册进**攻击方**桶）同处
   `BATTLE_FIRST/SECOND_SKILL_EFFECT` 桶同一张 map，按 key=(source_id<<32|effect_id) **升序**
   执行（`timed_bucket.h`）→ 1164 先写 `max(自然倍数, 2.0)`，2197 后写池内最低倍数**无条件覆盖**。
3. 推论：任何"锁倍数/改倍数"类效果与链接同场，默认按**来源 id 小者先写、链接后写必赢**。
   将来若有"链接锁不住"的官方反例，再引入显式协作位。

   - 760 确实是**精灵王统一效果**：全部王·第五（焚天君焱 17299 / 光璨九州 17514 / 冰魄天霜
     17774 / 逆流加农炮 17946 / 雷鳞机甲 17950 / 巨龙神威 17954…）都带 [760,…]；精灵王线
     还把"技能全集含 760"定为 `is_spirit_king` 官方判据（`pet_factory.cpp:205`）。
   - 但官方机制帖（语料 opus 791433890174599175《机制解析—变威力》④⑤）：**精灵王第五是
     "无视微弱"（微弱<1 抬 1，克制保持），光螳螂是"强制 2 倍"（任何系别倍数都写死 2）**——
     前者是下限钳制，后者是固定值硬锁。英卡洛斯 1164"至少为 2"属**螳螂族**（官方
     "魂印和技能强制锁定克制倍数"结算段），不属 760 族。
   - 两族唯一共同点：都是官方"补丁效果"，**不被变威力重算覆盖、两次伤害计算都生效**。
     引擎里天然满足：`restraint_view` 在 SKILL_EFFECT 写入后，变威力第二次

     不是 max 钳）。

     引擎现状，待观察。
