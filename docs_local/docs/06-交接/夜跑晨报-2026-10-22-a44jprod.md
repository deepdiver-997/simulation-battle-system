## J284 断言口径与实测

- **精确槽位**：消强前 `ability_levels[0][0]=2`、`[0][4]=1`，消后两槽均 0；
  不用"等级和"。
- **绝对量**：固定伤害是确定值——消 2 项 = **160**；两次独立消除累计 **320**；
  无提升/窗外/自己清自己/非自身被消均 **0**。
- **前提升级项数**：给出 +2 单槽仍只算 **1 项**（原语按槽计，不按等级值计）——
  首版 T6170.c 按 2 项写导致 cleared=1 失败，已修正为两槽 +2/+1；
  这是本族最容易写错的断言口径。
- **门隔离**：T6170.g 让对手清自己的提升（target=1、actor=1），隔离
  `ev.target==self` 门；T6170.d 隔离 `actor==self` 门。
- **变异**：M1 去 target 门 / M2 按次而非按项 / M3 打错目标 / M4 窗长改 30 /
  M5 去 actor 门 → **5/5 转红（exit 134）**，还原后 28 checks 全绿。
