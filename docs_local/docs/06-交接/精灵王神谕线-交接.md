## 五、视图层命名表/广播设计建议（2026-09-25，待实现）

  map value 里塞 string**——塞 string 的写入点分散在每个插件（命名不一致、漏写无法
  约束），静态表一处集中、可启动审计（所有已发布 key 必须有名）、协议只发 int key。
