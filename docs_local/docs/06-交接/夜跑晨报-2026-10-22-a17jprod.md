## 五、勘误记档

1. **`tools/agents/gate.sh` 等锁崩溃（本轮修复）**：锁 owner 文件按
   `echo "$$ ${PWD} $(date +%s)"` 写成**一行三字段**，读取却用 `head -1`/`tail -1`
   取"两行"——两处都拿到整行。`kill -0 "<整行>"` 必失败 → 误判持有者已死；
   随后 `$(( now - since ))` 把整行当算术表达式求值，路径词 `/private` 被当变量名，
   `set -u` 下报 `private: unbound variable` 直接退出。**后果**：任何并发构建时
   后来者的全量门必定崩溃（只影响"等锁"，不影响已持锁者）。修法：`awk` 取第
   1/3 字段 + `since` 非数字回退 0。
2. **worktree 看板副本与 hub 不一致**（a08 已记，本轮再次实证）：worktree 的
   `docs_local/...` 停在派生时快照，直接跑 `python3 tools/taskctl.py list` 会看到
   过期的"待领取"。夜跑脚本走 `$HUB/tools/taskctl.py`，以 hub 为准。
3. **hub 分支被并行会话切换**：开工时 hub 在 `feat/jbatch`，收尾复核时已在
   `main-local`（并有其他会话的看板 commit 与未提交 K 板文件）。本会话只读、
   未干预；合并/切换由集成会话负责。
4. **J234 的 722/722 已由 a12-jprod 在 done summary 登记**；本会话独立重跑全量门
   复现同一结果（722/722、moves 1286），两处证据一致。
