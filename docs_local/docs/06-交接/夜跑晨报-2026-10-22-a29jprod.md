## 四、勘误与记档

1. **NextRounds + AFTER_ACTION 的 roundCount 语义**：`round N` 的 ROUND_START 时
   `roundCount == N-1`。NextRounds 起点 `roundCount+1` 在**施放当回合**的 AFTER_ACTION
   尚未过期（`roundCount < start`）→ 若窗口挂在 AFTER_ACTION，会在施放当回合多跳一次。
   正解 = payload 带 `arm_round`，tick 用 `c->roundCount <= arm_round` 挡掉首跳
   （J70 同款）。639 首版实测 ticks=2，加守卫后 ticks=1。
2. **taskctl 路径分裂（复现 a27 记档）**：worktree 内 `python3 tools/taskctl.py` 写
   分支内看板副本，`finish.sh` 走 `$HUB/tools/taskctl.py` 所以 done 报"没有 🔄 行"。
   本会话沿用 a27 操作口径：claim/done 全部用 **worktree 内 taskctl**，任务行与
   tasklog 落在 `feat/jbatch`，合并后与主板一致。busy 清理仍用 `agent_id.py idle`。
3. **1462 已是 J171 实现**（`j_window_fixed.cpp`/`j_skill_window3.cpp` 双注册，
