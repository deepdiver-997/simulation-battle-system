2. **误领 J307**（`taskctl claim --board J` 取最小待领取号 → 领走了 a67 的 J307）：
   立即 `taskctl release --force` 退回（tasklog 留 `forced_from`），再按号领 J309。
   **教训**：`taskctl claim` 不带 id 会领**最小序**待领取单，必须显式带单号；
   且 `TASKCTL_WORKER` 未导出时 worker 退化成 `zhr@pidNNN` → 行属主对不上、
   `release` 被拒（本轮以 `--force` 退回）。
3. **`.agent-env` 不含 `SBS_AGENT_ID` / `SBS_AGENTS_DIR`**（沿用 a64/a67 勘误）：
   本轮手工 `export SBS_AGENT_ID=a68-jprod TASKCTL_WORKER=a68-jprod`（每次 Bash 调用
   重新导出——shell 状态不跨调用持久）。`source .agent-env` 本身无副作用。
4. **变异测试复原必须 `touch`**（沿用 a67 勘误 2，本轮再次踩到）：`cp` 复原源文件后
   `make` 判定 .o 仍比源新 → **不重编** → 变异码留在 dylib → 复原后自己的场景假红。
   本轮脚本统一 `cp 复原 + touch` 后再 `cmake --build`，并在每次变异后重建确认绿。
5. **分支现状**：`feat/jbatch` 是 J 板的**共享分支**，多会话顺序提交（a67 → a68）；
   本轮 3 单的提交在上面，`git log` 可按 a68 时间窗区分。
