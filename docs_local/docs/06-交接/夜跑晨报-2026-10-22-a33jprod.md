## 勘误记档

1. **finish.sh 的板/仓根口径**：`tools/night/finish.sh` 默认 `SBS_NIGHT_BOARD=K`，
   且 `lib.sh` 用 git-common-dir 解析 `HUB`（= hub main-local，J 板停在上次合并的
   J250）。J 板任务必须：
   `SBS_HUB=$PWD SBS_NIGHT_BOARD=J sh tools/night/finish.sh <单号> ok "..."`。
   否则报"没有 🔄 进行中 行"（会在 K 板/hub 旧板上找）。建议编排会话在 spawn 环境
   固化这两个变量，或让 finish.sh 按单号前缀自动选板。
2. **finish 记录的 impl_commit 受共享 worktree HEAD 竞态影响**：本单看板状态列记的
   `feat/jbatch d3df4afd` 是 finish 时刻 HEAD（a34 的 J262 领取提交），真实实现提交
   **cc56b334** 已写进 summary 文本。共享 worktree 多会话并发时，finish.sh 取 HEAD
   作 impl sha 的写法会串单。
3. **睡眠门时点**：`battleFsm.cpp` 的 ON_SKILL_HIT 在 SKILL_EFFECT **之前**解除睡眠
   （battleFsm:231-234），因此"出手时判任意异常"对睡眠恒闭。场景 f 已把该行为锁死；
   与 K2"命中即醒"一致，但官方文本下"打醒当刀是否仍算异常状态"未独立验证。
4. **共享 build/ 目录**：a33 与 a34 在同一 worktree 并发；08:19 全量构建曾在 a34
   场景文件编辑中途编译，出现一次瞬时 5910 红，08:22 后复跑转绿。最终门在无并发
   构建窗口内跑出 749/749。
