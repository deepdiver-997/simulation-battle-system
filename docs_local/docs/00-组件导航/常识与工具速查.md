## 一、ID 口径

| 规则 | 说明 |
|---|---|
| **精灵 id ≤ 5000 才是真实精灵** | monsters 表里 >5000 的大 id（如 1400739 肯扎特皮肤、5421-5426 六水沧岚形态、1400132 沧岚之水）是**皮肤/活动形态/变体**，不进常规对战池。查精灵时永远 `WHERE id <= 5000`。 |
| 技能 id 无此限制 | moves 表 id 直接增长（38xxx 最新技能段），效果 id（effect_info）是独立空间。 |
| 效果 id 段常识 | 697/699 = 穿透凭证（内核 `penetration_flags`，registry 曾假阳性漏记）；270210 = 元神变体（技能id×10，刻意避开 DB 空间）；8000~9000 段空置待扩。 |
| 场景编号 | 全库唯一顺延（当前用至 600）；夜跑分配器每任务预留 10 个号段，冲突以分配器为准。 |

### 4 水清泪的时点口径（2026-09-29 用户定稿）

清泪（魂印 1005）挂在**"被击败"时点**——官方文本就是"被击败时清除对手身上的水"。
若击杀机制**绕过该时点**（如梅赫维特/星皇系魂印的非常规击杀，不走常规被击败判定），
**不清泪、挡伤失效残留 = 正常游戏流程**，不是 bug、不做防御性修复——引擎忠实于
官方时点表述。调挡伤失效相关场景时注意这个口径。

### 4 水的两条路面与不管面（R3 收口，2026-10-01 场景 883 实证）

4 水（蚀砚之泪 ≥4 滴）有**两条独立路径**，别混：
- **掩码面**：对手 `damage_suppress_mask` 置 BLOCK|DETECT → 挡伤**票**（RuleCenter
  DAMAGE 类）整段被跳过、伤害落地（场景 600 T2 / 883c）；
- **窗口面**：沧岚方 `grant_penetration(PENETRATE_ATTACK, ignore_attack_immunity)`
  → 只穿**可穿攻击免疫/狮盔**；管线 BLOCK 回调只查 `is_immune(DAMAGE)`、**不问攻方
  穿透凭证** → 免伤票（2343 循环挡票类）照挡不误（场景 883b，BLOCKED 恒定）。
- **两路面都不含**：龙威/无效化盔（penetrable=false）与减伤（减伤不是挡伤）——
  R3 控制台观测的 BLOCKED 即龙威类（原"4泪穿透漏覆盖攻击无效化"系误归因，行为正确）。

## 三、枚举与槽位常识（写效果/场景前先对表）

| 项 | 口径 |
|---|---|
| moves.category | **1=物理攻击、2=特殊攻击、4=属性攻击**（power 0）。 |
| skill_type | **0=物理、1=特殊**；伤害公式攻取 `type`、防取 `type+2` → **等级槽 2=防御、3=特防**。 |
| 能力等级槽序 | **0攻 1特攻 2防 3特防 4速 5命中**（±6 钳制）；等级槽 5=命中 ≠ 数值属性槽 5=体力（两套索引只在前 5 重合）。 |
| 477 六槽参数 | effect 477 的 args[3..8] 是**语义序**（攻,防,特攻,特防,速,命中）→ 槽序映射 `{0,2,1,3,4,5}`。 |
| **属性排列双序（⚠️ 高频坑，已三处复现）** | 官方文案/参数里的属性排列**没有统一序**，动工前必须用 4399 载体文本交叉验证映射表：①**语义序**（攻,防,特攻,特防,速,命中）——477 六槽降级表；②**官方码序**（0攻/1防/2特攻/3特防/4速）——593 的 {1} 属性码（16115 [0,0,15]/16134 [1,3,100] 交叉验证）。按引擎序直读会把防/特攻读反。 |
| 官方异常码（0-9） | 0麻痹 1中毒 2烧伤 3寄生对手 4寄生 5冻伤 6害怕 7疲惫 8睡眠 9石化（AbnormalStatusId，全集 ≤43）。 |
| 限制类异常 | **只有瘫痪(19) + 凝滞(32)**（is_restriction_abnormal_status）；控制类是另一张表（诅咒 23 官方自述即控制类）。 |
| 伤害类型 | NORMAL 红伤（吃护盾）/ FIXED·PERCENT·PERCENT_VALUE 粉（吃护罩）/ TRUE 真（直通）/ ATTRIBUTE 属性直伤——BattleEvent.damage_kind（E12）。 |
| 挡伤 vs 减伤 | BLOCK（归零类：可被"挡伤失效"无视）与 MITIGATE（数值削减：**不可**被无视）必须分开声明——DamageEffectCategory。 |

## 四点五、技能"使用/类型"判据（2026-10-03 判据统一，写效果前必读）

| 要判什么 | 用什么 | 语义 |
|---|---|---|
| 本回合是否**成功使用**过技能 | `executed_skill_this_round(ctx, side)` | skill_use_seq（执行主流程 ++）较回合初基线（ws.skill_use_seq_round_start，FSM 快照）有增量；**被控/嗑药/NONE 不算使用**（裁定 2026-10-03），miss/被盔算 |
| 成功使用的技能是不是**攻击技** | `executed_skill_is_attack(ctx, side)` | 读 `ws.skill_type_view`（**实际物化类型**）——替换技/变型技（天启星魂 2210 式）正确；仅在本回合确有执行时调用 |
| 选择期判"选中的技能"类型/是否攻击技 | `selected_skill_is_attack` | 静态 type（技能未出，视图是旧值）；条件先制族/"下回合攻击技"预判门专用 |
| 选择位语义的"点了技能吗" | `used_skill_this_round` | roundChoice 选择位（被控也 true）——仅限确需"选择了"语义的旧效果 |

- **类型钦定槽 = `ws.skill_type_view`**：resolve_skill_execution 物化 executing skill 类型（替换技走 resolve_executing_skill）；变型技直接写它（天启星魂 2210 范式：view + element_view + force_involve + power_view）。伤害公式/特性门/FSM 属性门全消费它。新写"对手使用X技能后/每次使用攻击技"类效果**一律用 executed_* 助手**，不得再用 used_skill_this_round+selected_skill_is_attack 配对。
- **对手行动后+未触发兜底**：锚点一律 ROUND_END 桶（对手 NONE/被控回合其 AFTER_ACTION 桶不跑，挂对手名下=兜底死）；"使用"判据按上表。范式见 1053（j_hit_window.cpp）。
- 记档：EVENT_SKILL_USED 的 `used_attribute` 载荷 = **声明类型**（execute 起点发，变型前）；battleFsm 烧伤减半（:497 附近）读静态 type 且在物化时判——变型技+烧伤的组合未验证，动前先查。

## 五、场景编写常识（踩过的坑，勿再踩）

- `make_pet(id, name, skills, speed, atk, hp)`：**atk 同时设物攻+特攻，防御恒 100**；伤害断言前先确认攻防面板量级（atk=1 打什么都只有 1-2 点）。
- 威力 0 的**物理/特殊攻击技**仍有 1 点保底伤；**属性技（category=4）无伤害阶段**——完全不掉血、不进伤害管线（G5 发现）。精确 hp 断言的 filler 用 `ActionType::NONE` 出手最干净。
- 伤害公式有 **85%~100% 随机浮动**——精确等式断言不成立，用比例/上下界。
- **红伤浮动实测锚（2026-10-13 K 系夜跑回归勘误）**：atk300/def100 拍打 raw ∈
  **[87,102]**（B=102×[0.85,1.0]，随攻击面板线性缩放，atk600→[174,204]）。数值带
  断言必须以 (85,104) 为 raw 带做推导，**禁止拿单次抽样的最小/最大值当边界**
  （k 系曾按抽样 [62,99] 设带，上界 99 被实测 102 打穿）。比例派生带（×0.35/0.5/
  0.6/1.4/1.5/2）按 [87,102] 推导后再外扩 ±2 余量；相邻档位带间距 < 波动幅度时
  改用比值断言（d2/d1）或审计槽精确选档。
- 跨回合 watcher 必须 `WatcherScope::TEAM`（ON_STAGE 的 valid_id 活不过回合交界）。
- 技能固有 priority 经 `ws.preemptive_level` 残留跨回合——先制对照必须 priority=0 载体。
- IMMUNE 票（47 免弱）是纯查询类、不算"可断回合类"——造可断票用 `seal_skill` 直调。
- 新场景/新文件 `git add -f`（ignore 会静默吞）。
- **effect 参数切片双表口径（2026-09-30 实测事故，R1 已修 13 处/3 处口径差异）**：
  运行时切片数取 `side_effect.arg_count` **优先**、effect_info.args_num 兜底——两表
  曾有 **16 处不一致**（73/116/117/118/596/816/919/1154/1515/1531/1654/1794/2001/
  2190/2191/2217，逐条结论见 R 组工单 R1 节）。写效果实现时**不信任切片**：用
  effect_info 模板 {n} 个数 + 4399 载体文本反推参数。
- **author 切片必须 `json.loads` 后按 `side_effect.arg_count` 位切**（2026-10-07 J185 实测）：
  对 side_effect 原始字符串直接切片是**按字符**错位——1953 全量错切、重切后 9/9 自洽；
  与上条双表口径同源（arg_count 优先、args_num 兜底）。
- **窗式 ignore_pp 没有每回合重置**（2026-10-07 J184 实测）：ignore_pp 只在换宠/
  clearAllEffects 时清，**窗外回合残留** → "N 回合内 PP 无消耗"窗必须照 2492
  "每回合无脑重写"形：窗长注册 N+1、tick 携带 until、过期首回合显式清 false。
  场景断言窗后回合的命中/闪避前，先查载体 ignore_pp 残留。
- ~~`disabledEffects.soulMarks` 误伤技能效果~~ **R2 复核关单：引擎无缺陷**。禁魂印
  2231 后 46 免伤票"消失"是**观测时点伪影**——免伤票**当回合即生效**：施放同回合
  的对手攻击会被正确挡下并消耗，r0 末快照自然见不到票（场景 873 关单）。做禁魂
  对照实验时，对手首攻要放到下一回合，或用 BLOCK 事件而非回合末票快照取证。

- **并行批次的"链激活"陷阱（2026-10-02 合并 J12-J51 实证）**：场景载体链上的未实现
  兄弟效果随时会被**并行的其他任务**实现——写场景时按"链是哑的"钉的精确断言会在
  合并后翻车（实证：28138 链上 1265[1,100] 被激活 → R3 那刀被全免；37503 的 1522
  阈值 300 贴浮动带 → 兄弟效果改 rand 序后必挂）。防线：①载体优先选**纯链**
  （单效果）或全链已实现且良性；②阈值断言必须离浮动带下限（85%）有足够裕量；
  ③概率类兄弟效果（如 36 命中 1% 秒杀）会给同文件后续用例平移 rand 序——精确带
  测试要能容忍这一点。

- **禁用 `while(!FINISHED) step()` 步进对局（2026-10-26 场景 049 挂死实证）**：
  对含「受伤>阈值回满」「保留 1 点体力不死」「每回合回复」类魂印的对局，以
  FINISHED 为出口的步进循环**永不结束**——犀牛 1217 必暴 500+ 伤每回合都被回满
  分支吃掉，全量回归被卡死 20+ 分钟（sample 实证空转在 need_input→wait_for_input）。
  断言取**单回合** `run_round`/`submit_operation`+有限 step；要逐步观测就给循环加
  **回合数上限**（如 `for (int r=0; r<8 && !FINISHED; ++r) step()`）。回归循环已有
  单场景 60s 超时兜底（build.sh `SBS_SCENARIO_TIMEOUT` 可调）——TIMEOUT 行也是红，
  出现即查本条反模式，别当编译失败排查。
