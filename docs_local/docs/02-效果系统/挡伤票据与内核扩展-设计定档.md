## 二、挡伤票据（✅ 机制早已存在——2026-09-29 落地时的重要发现）

**实施时发现本节前提需要修正**：挡伤体系在活动版索伦森 1011 线（场景 080，
soul_lib/chaos_sorensen.cpp）**已经完整落地**——RuleCenter `DAMAGE` 票 +
`DamagePipeline::BLOCK` 阶段 + 沧岚"挡伤失效"抑制门（`pet.damage_suppress_mask`，
蚀砚之泪≥4 滴置 BLOCK|DETECT 位）三者齐备，且 DAMAGE 票**天然吃抑制门**（统一化
自动达成，无需任何两两硬编码）。2026-09-29 本轮只做了**缺口补齐**：
794（消强→回合窗挡伤）/ 1882（下只登场挡 N 次+凝滞）/ 49（护体族走护盾通道
`shield_bank_.add`——数值吸收不建并行票）/ 2360（816 helper 的注册包装，
damage_modifier.cpp）；688（零引用）/ 2292（缺武道衍化状态机）跳过记档。
场景 600 补技能侧挡伤×抑制门集成（魂印侧 080 已有）。

**用户定稿架构（原文保留）**：挡伤是经典机制，写入内核统一建模，拆**抵挡**与**施加**两步。

### 2.1 票据
- 新 RuleCategory `BLOCK_DAMAGE`，两种消耗模型：
  - **次数型**：46「抵挡下{0}次对手的攻击」、688、1882（下场精灵版）；
  - **数值型**：49「可以抵挡{0}点伤害」；
  - 混合/条件：794（消强成功→挡{0}回合）、2212（威力≤{1}才挡，未触发则挡当次）。
- 插入点：伤害管线**护盾吸收之后、落血之前**（`deal_damage` 内
  `shield_bank_.absorb` ~996 行附近）——挡伤吃"护盾后剩余量"。
- 触发语义：有票 → 本次伤害归零 → emit 广播。

### 2.2 广播事件（❌ 实施结论：不需要——相位回调更强且已有先例）
原设计 emit `EVENT_BLOCK_RESOLVED`；实施发现 **BLOCK 相位回调**（816/2360 的
`arm_immunity_reflect_true` 先例：注册在 `DamagePhase::BLOCK`、天然拿到被归零前的
final=免疫量）已覆盖"按挡下量反馈"的全部需求，且自带顺序语义（先消费票的默认回调
归零、我方回调拿值——816 注释有完整分析）。**按挡下量反馈的效果直接注册相位回调**：
- 2292（武道）：待"武道衍化轨迹"状态机建立后同款接入；
- 2292（武道）：挡下的伤害以固伤反馈（官方统一形状原型）；
- 816（弦月锋华 25848）：免疫下{0}次伤害**并附加免疫量的真实伤害**；
- 2360（王·龙予狂宴 29187）：免疫下次攻击伤害并附加免疫量真伤；
- 反弹真伤 = 消费方自选 `deal_true_damage`，票本体不关心反馈形态。

### 2.3 "挡伤失效"抑制门（✅ 早已实现——原"凭证"表述修正）
- 实现形态**不是凭证票，是状态掩码**：`ElfPet::damage_suppress_mask`
  （BLOCK|DETECT 位），挂在**被挂泪方**宠物对象上；
- 授予/撤销只有两个事件点：**挂泪**（魂印 1004：加滴数后 `sync_eternal_tear_suppress_mask`
  ——≥4 滴置位/<4 清位）与**沧岚死亡清泪**（1005 清 mark 后重 sync）。**没有**
  "每次对手登场都判断"的全局监控——掩码是持久状态，管线 walk 与 soul_lib 守卫函数
  在**伤害时刻现读**，登场与否不影响；
- 生效路径：管线 walk 执行每条伤害效果前查所属方掩码 → 被抑制的 BLOCK/DETECT
  条目**整条跳过** ⇒ 票**不触发也不扣次数**（索伦森③票，场景 031 Q4 契约；
  MITIGATE 减伤条目不受影响——"减伤 100% 不能被无视"）；
- soul_lib 直调守卫函数不经过管线 walk，自读同一掩码（`damage_guard_suppressed`
  ——真相源是掩码本身，插件不维护 allow-check 列表）；
- 2212 的"未触发则抵挡当次"是票的**条件挡**变体（已实现）。
- **清泪时点口径（用户 2026-09-29 定稿）**：清泪（1005）挂"被击败"时点——非常规击杀
  （绕过该时点，如梅赫维特/星皇系魂印）不清泪、抑制残留 = **忠实官方文本的正常行为**，
  非缺陷不做修复。

### 2.4 与受击回声族的边界（E12 已实现，feat/e12 c92ff5a）
- **挡伤票族**（本文）：先挡掉再反馈——46/49/688/794/1882/2212/2292/816/2360；
- **受击回声族**（✅ E12）：照常挨打 + 事后回敬——462（挨打反固定200）、
  580（反馈40%伤害）、1219（伤转自体回血，E2）——EVENT_TAKE_DAMAGE watcher
  可达，**不进票据**；`BattleEvent.damage_kind` 字段已随 E12 落地（红/粉区分）。

## 三、状态窗口事件（✅ 已实现，feat/e13 d82f082）

- `EVENT_SKILL_USED`（使用即触发：miss/被封也算，`used_attribute` 标记）
  ——Skills::execute 起点 emit；
- `EVENT_STAT_BOOSTS_LOST`（`stat_loss_kind`：0 消除 / 1 被吸取）——
  clear_stat_boosts / transfer_stat_boosts 成功路径 emit；
- 477"受到攻击"复用现有 `EVENT_HIT`（命中即被打到），零额外内核；
- ⚠️ 477 六槽参数是**语义序**（攻,防,特攻,特防,速,命中），映射槽序
  {0,2,1,3,4,5}——环流回声/地灵之缚/自然平衡三例 4399 交叉验证。

## 四、测试坑记档（三任务共用）

| 坑 | 结论 |
|---|---|
| WatcherScope 跨回合 | 跨回合 watcher 必须 `TEAM`——`ON_STAGE` 的 valid_id 判定活不过回合交界（1219/E12 两次踩） |
| 伤害公式随机浮动 | 85%~100% 随机 → 精确等式断言不成立，用比例断言（阈按失效倍率差设计） |
| 真技能链噪音 | 携带技能链上的强效果（1164 反转/118 随机威力/1653 固伤）会淹没目标效果断言——挑链或降级为冒烟+共路径覆盖记档 |
| priority 残留 | 技能固有先制经 `ws.preemptive_level` 残留跨回合——先制对照必须用 priority=0 载体（E2/T3） |
| 威力 0 技能 | 仍有 1 点保底伤——精确 hp 断言的 filler 用 `ActionType::NONE` 出手 |
| IMMUNE 票不可断 | 47 免弱票是纯查询类，不计入 `has_round_type`——造"可断回合类"用 `seal_skill` 直调（330 同款） |
