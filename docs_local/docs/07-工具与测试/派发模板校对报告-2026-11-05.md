## 四、失真模式归纳（为什么会错引）

1. **通道成果串写**（S23 主案 + #7/#13/#14）：「低伤转吸取/模式切换」是 K406 1464
   的实证成果，被记忆串挂到同期邻近单 K396 名下。K396（7500 段）与 K400/K406/K409
   （7540-7690 段）同周批产，单号邻近 + 通道词（补偿/切换/消除）在行文里都是
   「K396/K40x 同族」缩写，检索时互相污染。
2. **id 尾位丢失/邻近串写**（#3「120←1204」；#2「759←与 756 邻近」）：手写先例引用
   时不回查注册表。
3. **同族文件名串写**（#4 两个 mirror 族文件；#2 batch_a vs j_purge_roundly）：
   语义近族多文件并存时，凭印象写文件名。
4. **幻觉文件名**（#1 j_repair_drain.cpp）：先例引用从未存在的文件——
   「j_ 前缀+语义拼词」符合命名直觉，作者当轮凭空构造，无人核过存在性。
5. **撞号与官方多行两类问题混写**（#8）：夜跑撞号事故（audit 5 判例）被归因写成
   「官方多行」机制例证；两类的自查手段不同（dump 对行 vs 全库并集 grep），混写后
   纪律不可执行。
6. **写死会漂移的数字**（#9 673 基线）：场景总数每周增长（673→924），模板里写死
   必然过期。
7. **K/J 板号对调与空间串写**（S24 看板行自身把 k_prob_compensate.cpp 写在
   moves_lib）：魂印（soul 空间）/技能（moves 空间）同 id 两套语义，「低伤转吸取」
   在 moves 空间另有其人（K406 1464 也是 soul 空间；moves 空间同类为 J42 989
   低伤固伤族），空间不核对即串写。
