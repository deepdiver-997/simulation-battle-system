## D5（官方口径）：最后一只死亡效果不救终局——"结束标志位"模型

- **用户实测（重生之翼案例）**：对面最后一只重生之翼死亡 → 对局直接结束；但动画可见
  复活计数跳动（1→2）——**死亡效果实际结算了一瞬，但状态机随即终止**。
- **定档 = 结束标志位模型**：死亡漏斗完成即评估终局并**立标志**（判定基准 = 死亡登记
  名单：某方在场宠死亡已登记且无存活替补 → 终局标志）；其后亡语/复活 watcher **允许
  结算**（与动画计数一致），但状态机看到标志直接 FINISH，**不因亡语复活回滚终局**。
- 真两命（拦截器层自己复活，如重生之翼自复活）发生在死亡成立**之前** → 不进死亡名单
  → 不触发终局 ✓ 与"拦截器复活不救终局"自然区分。
- 落点 = D4 的检查函数按"死亡登记 + 无替补"判，且判完立即立 ctx.finish_flag，回合流程
  各检查点（含死切入口）见旗即走 FINISH。

## 落地清单

1. `BattleContext`：`max_rounds`（0=无限）+ `finish_flag` + `std::function<void(BattleContext&)> on_finish`。
2. `battleFsm`：ROUND_START 入口回合上限检查；死切入口（BATTLE_AFTER_DEFEATED →
   CHOOSE_AFTER_DEATH 跳转前）存活替补检查 → FINISH + on_finish；CHOOSE_AFTER_DEATH
   入口断言"在场宠确有死亡登记"（裁决终局性）。
3. 裁决后封闭逆转：heal_impl / revive 类原语对 `pet_death_notified` 已登记的宠 no-op
   （或 defeat 流程内清空其待结算治疗队列——按实现最小面）。
4. `legal_actions`：死切期输出集合去除 NONE/跳过；前端死切面板隐藏跳过按钮。
5. fuzz：设置 max_rounds + on_finish 计数，删除对应插桩；守卫降级为 unreachable 断言。
6. 场景：终局标志（最后一只亡语不救终局）/ 回合上限 / 死切合法集合 / 全灭直达 FINISH。

## 结算口径补强（2026-10-01 加测轮：终局即停 + 胜负快照 + 视为存活钩子）

**用户加测要求**：专门用例证明"最后一个死亡后不会开始下一个回合"；并核查薇尔诗
"黄金的万象"（似乎能"视为存活"、在结束后改变存活数翻转战果）是否意味着当回合要跑完。

**官方原文（effect_des 523，raw_json: kinddes=黄金万象, monster=4000）**：
> 自身登场时，消耗黄金万象并消除对手的回合类效果与能力提升效果，消除成功则1回合内
> 免疫受到的异常状态；**己方的薇尔诗在胜负结算中视为存活**

**结论（定档）**：
1. "视为存活"锚定在**胜负结算**层，官方没说当回合要跑完 → **当回合不跑完、下一回合
   永不开始**（维持 D5 模型），需要的是**结算口径**——与重生之翼实测（效果结算了一瞬、
   随即终止）拼合一致。
2. **压轴重生不改判**（用户口径"己方压轴击杀对手压轴重生也算自己赢"）：原
   battle_over 现场数 hp 会被亡语复活数出活口 → 平局化，违背口径。修法 =
   **终局快照**：`finish_battle()` 立旗瞬间按 hp>0 清点 `finish_alive_snapshot[2]`，
   胜负汇报读快照，晚到复活只结算不翻盘。
3. **视为存活钩子**：`settlement_treated_alive[2][6]`（默认 false）+
   `BattleContext::settlement_alive_count(side)`（快照 + 加回"已死但视为存活"的槽，
   汇报时点读取——亡语侧晚于立旗的置位赶得上）。battle_over_to_json 改走它。
   2513-② 实现方只需在她死亡时置位（她本体被消逝则不算——档案 §三'）。

**口径定稿（2026-10-01 用户游戏口径）**：①视为存活**以黄金万象未被消耗为前提**
（token 被持有者登场消耗后，加账随之撤销——2513-② 实现方在消耗时清
settlement_treated_alive 位）；②**视为存活的宠不可以继续出战**——终局直接结算，
"视为存活"只改结算存活数/胜负，不拦终局判定本身（evaluate_battle_end 不读该表，
现有接线即定稿，入口注释同步）。

**测试**：882 终局即停（亡语 drain 恰好 1 次 / ROUND_COMPLETION 0 次 /
roundCount 冻结 / ROUND_START 恰好 1 次=终局前那回合的自己）；883 结算快照
（A 压轴重生不翻盘：复活落地 hp=50 但结算仍 0 活口判负 / B 互灭平局 →
treated-alive 置位后翻为置位方胜）。回归 257/257 绿，fuzz 快扫 300 seed 全终局。
