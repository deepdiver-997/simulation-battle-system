   （复盘见 交接文档附录一；新精灵把 (monster_id, effect_id) 加进场景 137 的 kPairs）。
3. **场景编号从 140 起**（139=jiyuan 技能组、138=解析器、137=对齐守护已占）。
   ⚠️ `.gitignore` 有 `test/` 规则：**新场景文件必须 `git add -f`**，否则静默漏提交。
4. **顺序语义守则**（交接文档附录二）：顺序冲突优先换桶；同桶内数据序=执行序；
   不引入全局优先级表。凡依赖效果相对顺序的行为，场景断言锁死。
5. **验收**：新场景（每技能至少一条主路径断言 + 顺序敏感断言）+ 全套 `sim_scenario_*`
