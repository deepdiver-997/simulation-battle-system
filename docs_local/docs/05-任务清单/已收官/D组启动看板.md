0. **★ 领取/翻✅/退回一律走 tools/taskctl.py（2026-09-29 起，不再手改看板行）**：
   ```
   python3 tools/taskctl.py claim --board D            # 吐出序号最小的待领取（stdout 一行 JSON），自动改行+提交
   python3 tools/taskctl.py done D30 --commit <sha> --summary "实现一句话清单"

   ```

   抢失败会响亮报错，重跑即可，绝不静默覆盖。误领退回用 `release <ID>`。

   改看板 = 别的会话看不见 = 重复领取（2026-09-28 教训）。
   **领取时若发现本表已无【待领取】行**（全被领走/标 ✅）：不要空等，
   直接转 `docs_local/docs/05-任务清单/已收官/E组批量效果工单.md` 按其会话协议领取继续干活。
