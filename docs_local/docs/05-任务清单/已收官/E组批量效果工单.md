   `python3 tools/taskctl.py claim --board E`（省略 id = 吐出最小待领取，stdout JSON）、
   `done E5 --commit <sha> --summary "..."`、`release <ID>`、`list --board E`。
   看板对 agent 只读；flock+CAS 防双领取，抢失败重跑即可。登记处仍是 main-local 主检出。
1. **每任务 = 一个家族**：同一模板写一遍、多个效果 id 各一个 SKILL_EFFECT（或同 handler
   参数化），一个新文件 `resources/moves_lib/e_<家族名>.cpp`；场景每效果 ≥1 组。
2. 动工前置三查：①内核硬编码（防 697 式假阳性）②`effect_meta` 分类表 ③`grep 全库已有实现`
   （同族效果可能已随 D 组落地，如 582/919/1055 判据）。
3. 参数切片：`effect_info.args_num` 与 side_effect 切分（老三样）；int_args 前置
   `[owner, 视角占位]` 两位、模板参数从 [2] 起。
4. 解包不达预期**必须走 EFFECT_ARG_GUARD**（common.h），静默 return 会被检查点打红。
5. 验收/收尾/禁令同 D 组提示词模板（`D组提示词模板.md` 第二/三步 + 硬性禁令）。
6. 场景编号按上表段落自选（段内顺延），与全局分配器（claim 场景段 180 起每任务 10 个）
   并行——E 组**手工段**，若冲突以夜跑分配器为准重排。
